## Итоговый комментарий

Памятка по подключению Claude к Битрикс24 через входящий вебхук готова, 2 страницы, файл во вложении.
Вариант Claude: Claude Code в облачной сессии (claude.ai/code), REST API Битрикс24 вызывается через мой собственный входящий вебхук.

**Проверено самостоятельно:**
— официальный MCP-коннектор: добавлен, вход прошёл, запросы закрыты настройкой портала. По вашему решению не используется;
— создан собственный входящий вебхук, чужие вебхуки и ключи не использовались;
— в облачной сессии Claude Code запросы к порталу блокирует сетевая политика окружения (ошибка 403). Причина и способ решения описаны в памятке;
— в памятке нет паролей, ключей, адресов вебхуков и персональных данных.

**Не проверено (в памятке помечено ⚠️):**
— чтение своей задачи через вебхук и три примера запросов: ждут разрешения домена портала в окружении Claude;
— сообщения об ошибках прав (`insufficient_scope`, `ACCESS_DENIED`, 401): описаны по документации;
— чтение комментариев из «Чата задачи»: скорее всего, нужно право `im`.

**Нужно решение (до 3 вопросов):**
1. Как коллеги используют вебхук в Claude и есть ли у них готовая инструкция? Предлагаю: если инструкция есть, пришлите ссылку — сверю её с памяткой и подготовлю точечные правки. Если нет — эта памятка станет базовой.
2. Нужно ли Claude читать комментарии в «Чате задачи»? Для этого в вебхук надо добавить право `im`. Предлагаю не добавлять: в отчётах указывать это ограничение, а комментарии пересказывать вручную. Если чтение нужно — добавлю `im` только в свой вебхук и буду использовать его только для чтения.
3. Где хранить памятку? Предлагаю: пока только в этой задаче. После вашей проверки — в базе знаний отдела, в общей ленте не публиковать.
