# ОГЭ English — тренажёр

Интерактивный сайт для подготовки к ОГЭ по английскому языку. В нём 1338 заданий из открытого банка ФИПИ, ответы проверены на сайте ФИПИ.

| Раздел | Что внутри | Заданий |
|---|---|---|
| Задание 12 | Чтение: тексты A–F и вопросы 1–7 (соответствие) | 38 наборов |
| Задания 13–19 | Чтение: True / False / Not stated | 196 (28 текстов) |
| Задания 20–28 | Грамматика | 666 (74 текста) |
| Задания 29–34 | Словообразование | 438 (73 текста) |

Аудирования здесь нет: в выгрузке банка не было аудиозаписей.

**Возможности:**
- разделённый экран: слева текст (абзацы пронумерованы), справа задания; на телефоне текст сворачивается кнопкой;
- проверка как на ОГЭ, подсветка зелёным и красным, при ошибке сразу открывается пошаговый разбор;
- сохраняется вся история попыток;
- кабинет ученика: прогресс по разделам, точность с первой попытки, разбор своих ошибок;
- кабинет преподавателя: таблица всех учеников, карточка ученика с полным логом ответов, фильтр «Только ошибки», «слабые места», обновление в реальном времени.

---

## Стек

- **Интерфейс:** React 18, TypeScript, Vite. Получается статический сайт, его можно бесплатно опубликовать на Netlify, Vercel или GitHub Pages.
- **База и авторизация:** [Supabase](https://supabase.com): PostgreSQL, Auth (email или логин и пароль), Realtime. Бесплатного тарифа хватит на класс или школу.

## Структура базы данных

| Таблица | Назначение |
|---|---|
| `profiles` | ученики и преподаватели: имя, логин, роль, время последней активности, текущий раздел, текст и задание |
| `sections` | разделы (12, 13–19, 20–28, 29–34) |
| `passages` | тексты внутри разделов |
| `tasks` | задания. Столбцы `answers` и `explanation` закрыты от учеников |
| `attempts` | каждая попытка: кто, какое задание, какой ответ, верно или нет, когда |
| `app_settings` | секретный код преподавателя (клиенты таблицу не видят) |

Серверные функции:
- `check_answer(task, answer)` сверяет ответ на сервере, записывает попытку и только после этого возвращает правильный ответ и разбор. Подделать попытку или подсмотреть ответ заранее нельзя.
- `get_solutions(tasks[])` выдаёт разборы только тех заданий, которые ученик уже решал. Преподаватель получает любые.
- `teacher_overview()` возвращает сводку по всем ученикам, только для преподавателя.
- `become_teacher(code)` выдаёт роль преподавателя по коду.

Права доступа (Row Level Security):
- ученик видит только свой профиль и свои попытки, преподаватель видит всех;
- никто не может изменить себе роль или вписать попытку в обход проверки;
- гости без входа не видят ничего.

## 1. Посмотреть сайт без базы (демо-режим)

```bash
npm install
```
```bash
npm run demo
```

Откройте адрес, который покажет терминал (обычно http://localhost:5173). В демо-режиме всё хранится только в вашем браузере. Код преподавателя для демо: `demo-teacher`.

> Демо нужно только для просмотра. Для настоящей работы с учениками подключите Supabase (шаг 2).

## 2. Подключение Supabase (≈10 минут)

1. Зарегистрируйтесь на https://supabase.com и нажмите **New project**. Придумайте пароль базы и выберите ближайший регион (например, Frankfurt).
2. Откройте **SQL Editor → New query**, вставьте всё содержимое файла `supabase/schema.sql` и нажмите **Run**. Должно появиться «Success».
3. Задайте свой секретный код преподавателя: выполните в SQL Editor
   ```sql
   update app_settings set value = 'ваш-секретный-код' where key = 'teacher_code';
   ```
4. Откройте **Authentication → Sign In / Providers → Email** и **выключите «Confirm email»**. Это нужно, чтобы ученики могли регистрироваться по логину без почты и входить сразу.
5. Откройте **Project Settings → API Keys** (или **Data API**) и скопируйте:
   - Project URL;
   - `anon` / publishable key;
   - `service_role` / secret key.
6. В папке проекта скопируйте `.env.example` в `.env.local` и вставьте туда эти значения.
7. Загрузите задания в базу:
   ```bash
   npm install
   ```
   ```bash
   npm run push-tasks
   ```
8. Запустите сайт:
   ```bash
   npm run dev
   ```

> ⚠️ Ключ `service_role` даёт полный доступ к базе. Он нужен только для команды `push-tasks` на вашем компьютере. Никогда не публикуйте его и не добавляйте в настройки хостинга.

## 3. Публикация в интернете

```bash
npm run build
```

Появится папка `dist`, это готовый сайт. Самый простой способ опубликовать его:
- **Netlify Drop:** откройте https://app.netlify.com/drop и перетащите туда папку `dist`. Сайт сразу получит адрес.
- **Vercel или Netlify из GitHub:** подключите репозиторий, укажите команду сборки `npm run build`, папку `dist` и переменные окружения `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.

Сайт использует адреса вида `/#/...`, поэтому дополнительная настройка маршрутов на хостинге не нужна.

## 4. Роли

- **Ученик** регистрируется на сайте сам: имя, логин или email, пароль.
- **Преподаватель** назначается одним из трёх способов:
  1. при регистрации отметить «Я преподаватель» и ввести код из шага 2.3;
  2. уже зарегистрированный пользователь открывает «Мой прогресс» → «Я преподаватель — у меня есть код доступа»;
  3. вручную: Supabase → **Table Editor → profiles** → в столбце `role` у нужного человека указать `teacher`.

Чтобы поменять код, повторите запрос из шага 2.3. Старый код сразу перестанет работать.

## 5. Как проверяются ответы (как на ОГЭ)

- **Грамматика и словообразование.** Регистр и пробелы не важны: `Was Built`, `was built` и `wasbuilt` засчитываются одинаково. Орфография должна быть точной. Полная и краткая форма равноценны (`did not know` = `didn't know`), британское и американское написание тоже (`colourful` = `colorful`).
- **True / False / Not stated.** Выбирается один вариант: 1, 2 или 3.
- **Задание 12.** Каждому тексту A–F соответствует номер вопроса. Задание засчитывается, если верны все шесть позиций. Счёт «4 из 6» тоже сохраняется.
- Повторные попытки разрешены. В статистике отдельно считается «верно с первой попытки».

## 6. Как добавить новые задания

Все задания лежат в файле **`data/tasks.json`**: разделы, тексты и задания с ответами и разборами.

1. Откройте файл в любом редакторе (например, VS Code) и добавьте записи по образцу ниже.
2. Проверьте файл:
   ```bash
   npm run check-tasks
   ```
3. Загрузите в базу:
   ```bash
   npm run push-tasks
   ```

Повторная загрузка безопасна: записи обновляются по `id`, попытки учеников сохраняются.

**Новый раздел:**
```json
{ "id": "my-section", "title": "Задания 20–28", "subtitle": "Грамматика (вариант 2)", "kind": "gap", "sort": 5,
  "instruction": "Текст инструкции для учеников" }
```
`kind`: `gap` — текст с пропусками, `tfn` — True/False/Not stated, `matching` — тексты и вопросы.

**Текст:**
```json
{ "id": "g-new-01", "section_id": "grammar-20-28", "title": "My summer holidays", "body": "", "sort": 100 }
```
Для `gap` поле `body` оставьте пустым: текст на сайте собирается из предложений заданий. Для `tfn` и `matching` запишите в `body` сам текст, разделяя абзацы пустой строкой. Для `matching` каждый абзац начинается с буквы: `A. ...`.

**Задание с пропуском:**
```json
{ "id": "NEW001", "section_id": "grammar-20-28", "passage_id": "g-new-01", "sort": 1, "number": "20",
  "kind": "text", "prompt": "Last summer we _____ to the seaside.", "word": "GO",
  "options": null, "topic": "Past Simple",
  "answers": ["went"],
  "explanation": "Рассказ о прошлом, есть маркер «last summer» → Past Simple.\ngo — неправильный глагол: go – went – gone.\nОтвет: went." }
```
Пропуск в `prompt` — это ровно пять подчёркиваний `_____`. В `answers` перечислите все допустимые варианты. В `explanation` каждая строка — отдельный шаг разбора.

**True / False / Not stated:**
```json
{ "id": "NEW002", "section_id": "reading-13-19", "passage_id": "t-new-01", "sort": 1, "number": "13",
  "kind": "choice", "prompt": "The museum is open every day.", "word": null, "topic": "Чтение",
  "options": [{"value":"1","label":"True"},{"value":"2","label":"False"},{"value":"3","label":"Not stated"}],
  "answers": ["2"], "explanation": "..." }
```

**Соответствие (задание 12):**
```json
{ "id": "NEW003", "section_id": "reading-12", "passage_id": "m-new-01", "sort": 1, "number": "12",
  "kind": "matching", "prompt": "Установите соответствие...", "word": null, "topic": "Чтение",
  "options": { "letters": ["A","B","C","D","E","F"], "questions": ["Вопрос 1", "Вопрос 2", "...", "Вопрос 7"] },
  "answers": ["461537"], "explanation": "..." }
```
Ответ — номера вопросов по порядку для текстов A, B, C, D, E, F.

Можно добавлять задания и прямо в Supabase (**Table Editor → tasks**), но через файл удобнее и надёжнее: он проверяется командой `check-tasks`.

## Структура проекта

```
data/tasks.json          — все разделы, тексты, задания, ответы и разборы
supabase/schema.sql      — таблицы, права доступа, серверные функции
scripts/push-tasks.mjs   — проверка и загрузка заданий в Supabase
src/lib/                 — работа с базой (supabaseApi.ts), демо-режим, подсчёт прогресса
src/pages/               — страницы: вход, разделы, текст с заданиями, прогресс, кабинет преподавателя
src/components/          — карточка задания, разбор, полосы прогресса, таблицы
src/styles.css           — оформление (светлая и тёмная тема, адаптивная вёрстка)
```
