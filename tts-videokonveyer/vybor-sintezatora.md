## 2. Выбор движка

Все кандидаты уже работают на TTS-сервере 192.168.206.206 — ставить ничего не нужно.

| Кандидат | Лицензия (проверила по карточкам моделей) | Плюсы | Минусы |
|---|---|---|---|
| **Qwen3-TTS + адаптер ударений sknyazev** (8016) | Apache-2.0; в карточке: «все обучающие данные — под свободными лицензиями или в общественном достоянии» (LibriVox + фразы, озвученные ESpeech RL-V2) | клон нашего эталона — свой голос компании; ударения «+»; жду от Qwen наибольшей естественности — проверить на слух | нужен эталон с правом; скорость не измерена, очередь сервера общая; происхождение весов ESpeech — оговорка Николая |
| **Silero CIS Base** (8014) | MIT для этой ветки (Николай; совпадает с PyPI silero) | 29 готовых русских голосов, эталон не нужен; ручные и автоударения; CPU, быстро; WAV 48 кГц | без клона: голос не «наш»; при «+» размечать всю фразу |
| Vosk ru 0.10 (8016) | Apache-2.0 по каталогу | 57 готовых голосов, CPU | словарь ударений без контекста, числа только словами |
| Qwen + адаптер siriusfreak «CF» (8016) | Apache-2.0, **но** карточка сама предупреждает: тексты фраз из biggest-ru-book без лицензии, детектор ударений учили на аудио Silero (некоммерческое) | клон, «+» и U+0301 | для роликов клиентам — только после проверки юристом |
| OmniVoice (8009, Mac Studio), F5 Russian, Silero v5.5/5.6 ru, Higgs | некоммерческие | — | **не берём** (README) |

**Предложение.**
1. Основной голос — **Qwen3-TTS с адаптером sknyazev** и эталоном нашего сотрудника или диктора.
2. Резерв и голос на время до эталона — **Silero CIS Base**: лицензия MIT, эталон не нужен.
3. ГОЛОЛЁД пересобрать в обоих вариантах. Окончательно выбрать после прослушивания рядом с Piper и пилотом Rivc.FES.

Для внутреннего прослушивания Qwen можно взять серверный голос `russian-news`. В ролик для клиентов он не идёт: права на исходную запись не подтверждены.

Переключение между движками — одно поле `voice.engine` в story.json, код одинаковый.

## 4. Эталонная запись голоса (шаг 3)

- **Чей голос.** Сотрудник по письменному согласию или диктор по договору. В согласии или договоре указать:
  - синтез голоса;
  - ролики внутренние и для клиентов;
  - срок;
  - право отозвать согласие.

  Текст согласия проверяет юрист. Голоса из интернета не брать.
- **Запись.**
  - 10–12 с ровного чтения: эталон F5/ESpeech на 8013 принимается только 2–12 с, для Qwen этого тоже хватает.
  - Отдельно — 1–2 минуты того же голоса про запас.
  - Тихая комната, без музыки и эха; WAV PCM 16 бит, моно, 24 или 48 кГц.
  - Точная расшифровка текста — без неё клон не работает.
- **Загрузка.** Один раз через Swagger сервиса: `POST /v1/voices`, WAV и расшифровка. Полученный `voice_id` вписать в story.json.

  Запись хранится только во внутренней сети. Каталоги голосов у разных портов свои: для 8016 загружать на 8016.

## 5. Как выполнить шаги 2 и 4 на компьютере с VPN

1. Ветка от main в internal/collateral, применить патч из `mr-collateral/`:
   ```bash
   git checkout -b tts-local-voice origin/main
   git apply --check ПУТЬ/tts-voice-engine.patch
   git apply ПУТЬ/tts-voice-engine.patch
   git commit -a -F ПУТЬ/commit-message.txt
   ```
   Если `--check` не проходит — tts.py или README в main изменились после 02.11; тогда взять готовый `mr-collateral/tts.py`.
2. `engine/config.json` — добавить блок `tts_servers` (пример — README, раздел «Голос: движок синтеза»). `themes/gololed/story.json` → `voice`:
   ```json
   "voice": {"engine": "silero", "request": {"model": "v5_cis_base", "speaker": "ru_alexandr"}}
   ```
   Точные имена моделей, голосов и полей — `http://192.168.206.206:8014/models` и `/docs` (у 8016 — свои). В поле `tts` реплик поставить «+» в спорных словах: РИВЦ, SNOWTAM.
3. Пересобрать: `python3 engine/vc.py release gololed all`, послушать, затем то же с `"engine": "tts-lab"`.
4. **Проверка без внешней сети.** Внешний адрес не открывается (`curl -m 5 https://ya.ru` — ошибка), сервер отвечает (`curl http://192.168.206.206:8014/health/ready`), выпуск проходит.
   - Если VPN идёт через интернет, просто отключить интернет нельзя — VPN тоже отключится. Делать в офисной сети или правилом файрвола: открыть только адрес VPN-шлюза и 192.168.206.0/24.
   - Возможная помеха: `vc.py` вызывает HyperFrames через `npx --yes` и при пустом кэше npm идёт в интернет (README). Если выпуск упадёт на рендере — дело не в синтезе.
5. Замерить время: применение патча и настройка, синтез (tts.py печатает «синтез N с»), полный выпуск, прослушивание.
6. Merge request в internal/collateral. Описание: что сделано, итог проверки без сети, выбранный голос.
