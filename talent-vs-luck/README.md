# Победителей не судят. А зря… — пункт 5 «Неожиданные выводы»

Пять слайдов для общей презентации группы, на каждом график, мем и формулы.

- `Победителей_не_судят_с_п5.pptx` — вся презентация группы, новые слайды 17–21 стоят после «Карьера: удача старта и пути», перед «Спасибо».
- `п5_только_новые_слайды.pptx` — только эти 5 слайдов (2,6 МБ), чтобы импортировать их в общую презентацию.

Текст для доклада лежит в заметках к каждому слайду.

Модель та же, что на слайде «Если участников много»: 1000 участников, из них 10 талантов (p = 0,75)
и 990 обычных (p = 0,6), тест из 20 вопросов, ничьи разыгрываются жребием.

| Слайд | Главная мысль | Цифры | Мем |
|---|---|---|---|
| Кто на пьедестале? | Большинство победителей — обычные участники, потому что их в 99 раз больше | 74% побед у обычных; талант выигрывает в 35 раз чаще обычного; в топ-10 в среднем 1,5 таланта | Drake |
| Проклятие победителя | Балл победителя завышает его способности | видим 93%, на деле 64%; Муавр–Лаплас: k_max ≈ np + z√(npq) ≈ 18,8 из 20 | «Это гений?» (Is this a pigeon) |
| Регрессия к среднему | Удача не наследуется, и во втором туре топ-10 «проседает» | 17,5 → 12,4 балла; повторная победа — 0,7% | Buff Doge vs Cheems |
| Ошибка выжившего | 1000 трейдеров с монетками, в кадре только «гений» | M = 1000·2⁻¹⁰ ≈ 0,98; P(X ≥ 1) ≈ 0,62; Байес: P(талант \| 10 из 10) ≈ 0,05 | самолёт Вальда (нарисован заново) |
| Так судить ли победителей? | Главный вопрос и наше мнение | σ(X/n) = √(pq/n) | Panik–Kalm–Panik |

## Как пересобрать

```bash
pip install numpy scipy matplotlib pillow
python3 compute.py                      # все числа: точные (через распределение максимума) и симуляции
python3 make_figures.py                 # графики и формулы в figures/
python3 make_memes.py                   # мемы в figures/ (шаблоны скачиваются с imgflip в templates/)
python3 build_deck.py <черновик.pptx> Победителей_не_судят_с_п5.pptx
```

Для графиков и мемов нужны шрифты Golos Text и Oswald (Google Fonts). Формулы рисуются картинками в стиле LaTeX
(matplotlib mathtext, шрифт STIX), так же, как на остальных слайдах.
