# Типовой расчёт по кратным интегралам и теории поля — вариант 7

Решение шести заданий по методичке А. И. Попова и И. Ю. Попова
«Типовой расчёт по кратным интегралам и теории поля» (СПб, 2024, раздел 3):

- РГР 1 (кратные и криволинейные интегралы) — задания 1–4;
- РГР 2 (теория поля) — задания 5–6.

| Файл | Что это |
|---|---|
| `RGR_variant7_solution.pdf` | Готовое решение: условия, подробные пояснения, чертежи, ответы |
