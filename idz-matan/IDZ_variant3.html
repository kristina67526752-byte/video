Задача 1.9

Найти дифференциалы 1-го и 2-го порядков функции \(u = xy + yz + zx\).

Функция — многочлен, определена и дифференцируема при всех \((x,y,z)\in\mathbb{R}^3\).

1. Частные производные 1-го порядка

\[u'_x = y+z,\qquad u'_y = x+z,\qquad u'_z = x+y.\]

2. Первый дифференциал

\[du = u'_x\,dx + u'_y\,dy + u'_z\,dz = (y+z)\,dx + (x+z)\,dy + (x+y)\,dz.\]

3. Частные производные 2-го порядка

\[u''_{xx} = 0,\quad u''_{yy} = 0,\quad u''_{zz} = 0,\] \[u''_{xy} = (y+z)'_y = 1,\quad u''_{xz} = (y+z)'_z = 1,\quad u''_{yz} = (x+z)'_z = 1.\]

4. Второй дифференциал

\[d^2u = u''_{xx}dx^2 + u''_{yy}dy^2 + u''_{zz}dz^2 + 2u''_{xy}\,dx\,dy + 2u''_{xz}\,dx\,dz + 2u''_{yz}\,dy\,dz.\] \[d^2u = 0 + 0 + 0 + 2\,dx\,dy + 2\,dx\,dz + 2\,dy\,dz.\]
Ответ: \(du = (y+z)dx + (x+z)dy + (x+y)dz\); \(\;d^2u = 2(dx\,dy + dx\,dz + dy\,dz)\).

Задача 2.1

Найти \(\dfrac{dz}{dt}\), если \(z = e^{2x-3y}\), где \(x = \operatorname{tg} t\), \(y = t^2 - t\).

\(z\) — сложная функция одной переменной \(t\) (через \(x(t)\) и \(y(t)\)). Формула:

\[\frac{dz}{dt} = \frac{\partial z}{\partial x}\cdot\frac{dx}{dt} + \frac{\partial z}{\partial y}\cdot\frac{dy}{dt}.\]

1. Частные производные \(z\)

\[\frac{\partial z}{\partial x} = e^{2x-3y}\cdot(2x-3y)'_x = 2e^{2x-3y},\qquad \frac{\partial z}{\partial y} = e^{2x-3y}\cdot(2x-3y)'_y = -3e^{2x-3y}.\]

2. Производные \(x(t)\), \(y(t)\)

\[\frac{dx}{dt} = \frac{1}{\cos^2 t},\qquad \frac{dy}{dt} = 2t - 1.\]

3. Подставляем

\[\frac{dz}{dt} = 2e^{2x-3y}\cdot\frac{1}{\cos^2 t} - 3e^{2x-3y}\,(2t-1) = e^{2x-3y}\left(\frac{2}{\cos^2 t} - 6t + 3\right).\]

Выразим через \(t\): \(2x - 3y = 2\operatorname{tg} t - 3t^2 + 3t\). Формула верна при \(t \ne \frac{\pi}{2} + \pi k\), \(k\in\mathbb{Z}\) (там не определён \(\operatorname{tg} t\)).

Ответ: \(\displaystyle \frac{dz}{dt} = e^{\,2\operatorname{tg} t - 3t^2 + 3t}\left(\frac{2}{\cos^2 t} - 6t + 3\right)\).

Задача 3.4

Найти экстремумы функции \(z = z(x,y)\), заданной неявно уравнением \(x^2+y^2+z^2+4x-2y-4z-7 = 0\).

1. Что это за поверхность

Выделим полные квадраты:

\[(x^2+4x+4) + (y^2-2y+1) + (z^2-4z+4) = 7+4+1+4\ \Longrightarrow\ (x+2)^2 + (y-1)^2 + (z-2)^2 = 16.\]

Это сфера с центром \((-2;\,1;\,2)\) и радиусом \(R=4\). Уравнение задаёт две функции (верхнюю и нижнюю полусферы):

\[z = 2 \pm \sqrt{16 - (x+2)^2 - (y-1)^2},\]

область определения — круг \(D:\ (x+2)^2 + (y-1)^2 \le 16\) (рис. 1).

2. Частные производные неявной функции

\(F(x,y,z) = x^2+y^2+z^2+4x-2y-4z-7\):

\[F'_x = 2x+4,\qquad F'_y = 2y-2,\qquad F'_z = 2z-4.\] \[z'_x = -\frac{F'_x}{F'_z} = -\frac{x+2}{z-2},\qquad z'_y = -\frac{F'_y}{F'_z} = -\frac{y-1}{z-2}\qquad (z \ne 2).\]

3. Стационарные точки

\[z'_x = 0 \Rightarrow x = -2,\qquad z'_y = 0 \Rightarrow y = 1.\]

Подставим \(x=-2,\ y=1\) в исходное уравнение:

\[4 + 1 + z^2 - 8 - 2 - 4z - 7 = 0\ \Longrightarrow\ z^2 - 4z - 12 = 0\ \Longrightarrow\ z_1 = 6,\ \ z_2 = -2.\]

Получили две точки: \(M_1(-2;\,1;\,6)\) и \(M_2(-2;\,1;\,-2)\) (в обеих \(z\ne 2\), т.е. \(F'_z \ne 0\)).

4. Вторые производные (достаточное условие)

Дифференцируем \(z'_x = -\dfrac{x+2}{z-2}\), помня, что \(z = z(x,y)\):

\[z''_{xx} = -\frac{1\cdot(z-2) - (x+2)\,z'_x}{(z-2)^2},\qquad z''_{xy} = \frac{(x+2)\,z'_y}{(z-2)^2},\qquad z''_{yy} = -\frac{1\cdot(z-2) - (y-1)\,z'_y}{(z-2)^2}.\]

В стационарной точке \(x+2 = 0,\ y-1=0,\ z'_x = z'_y = 0\), поэтому

\[A = z''_{xx} = -\frac{1}{z-2},\qquad B = z''_{xy} = 0,\qquad C = z''_{yy} = -\frac{1}{z-2}.\]

Точка \(M_1\), \(z = 6\): \(A = -\tfrac14,\ B = 0,\ C = -\tfrac14\); \(\ \Delta = AC - B^2 = \tfrac1{16} > 0,\ A < 0\ \Rightarrow\) максимум, \(z_{\max} = 6\).

Точка \(M_2\), \(z = -2\): \(A = \tfrac14,\ B = 0,\ C = \tfrac14\); \(\ \Delta = \tfrac1{16} > 0,\ A > 0\ \Rightarrow\) минимум, \(z_{\min} = -2\).

Геометрически: это самая верхняя и самая нижняя точки сферы, \(2 \pm R = 2\pm 4\) (рис. 2).

Ответ: в точке \((-2;\,1)\): \(z_{\max} = 6\) (ветвь \(z = 2+\sqrt{\dots}\)) и \(z_{\min} = -2\) (ветвь \(z = 2-\sqrt{\dots}\)).

Задача 4.1

Для поверхности \(2^{x/z} + 2^{y/z} = 8\) и точки \(M(2;\,2;\,1)\): найти градиент, производную по направлению \(\vec l = \frac{1}{\sqrt3}(1;\,1;\,-1)\), составить уравнения касательной плоскости и нормали.

Проверка: \(2^{2/1} + 2^{2/1} = 4 + 4 = 8\) — точка \(M\) лежит на поверхности.

Запишем поверхность в виде \(F(x,y,z) = 2^{x/z} + 2^{y/z} - 8 = 0\). Используем \((a^u)' = a^u \ln a \cdot u'\).

1. Частные производные и градиент в точке M

\[F'_x = 2^{x/z}\ln 2\cdot\frac1z,\qquad F'_x(M) = 2^{2}\ln2\cdot 1 = 4\ln 2;\] \[F'_y = 2^{y/z}\ln 2\cdot\frac1z,\qquad F'_y(M) = 4\ln 2;\] \[F'_z = 2^{x/z}\ln 2\cdot\left(-\frac{x}{z^2}\right) + 2^{y/z}\ln 2\cdot\left(-\frac{y}{z^2}\right),\qquad F'_z(M) = 4\ln2\cdot(-2) + 4\ln2\cdot(-2) = -16\ln 2.\] \[\operatorname{grad} F(M) = (4\ln2;\ 4\ln2;\ -16\ln2) = 4\ln 2\,(1;\ 1;\ -4),\] \[|\operatorname{grad} F(M)| = 4\ln2\sqrt{1+1+16} = 12\sqrt2\,\ln 2.\]

2. Производная по направлению

\(|\vec l| = \frac{1}{\sqrt3}\sqrt{1+1+1} = 1\) — вектор уже единичный, \(\cos\alpha = \cos\beta = \frac1{\sqrt3},\ \cos\gamma = -\frac1{\sqrt3}\).

\[\frac{\partial F}{\partial l} = F'_x\cos\alpha + F'_y\cos\beta + F'_z\cos\gamma = 4\ln2\cdot\frac{1}{\sqrt3} + 4\ln2\cdot\frac{1}{\sqrt3} + (-16\ln2)\cdot\left(-\frac{1}{\sqrt3}\right) = \frac{24\ln2}{\sqrt3} = 8\sqrt3\,\ln 2.\]

3. Касательная плоскость

Нормальный вектор \(\vec n = \operatorname{grad}F(M) \parallel (1;\,1;\,-4)\):

\[1\cdot(x-2) + 1\cdot(y-2) - 4(z-1) = 0\ \Longrightarrow\ x + y - 4z = 0.\]

4. Нормаль

\[\frac{x-2}{1} = \frac{y-2}{1} = \frac{z-1}{-4}.\]
Ответ: \(\operatorname{grad}F(M) = 4\ln2\,(1;1;-4)\); \(\ \dfrac{\partial F}{\partial l} = 8\sqrt3\ln 2\); касательная плоскость \(x+y-4z=0\); нормаль \(\dfrac{x-2}{1} = \dfrac{y-2}{1} = \dfrac{z-1}{-4}\).

Задача 5.1

Вычислить \(\displaystyle\iint_D (x+1)\,dx\,dy\), где \(D\) ограничена линиями \(y = x^2\) и \(y = 2 - x\).

1. Область D (чертёж обязателен)

Точки пересечения: \(x^2 = 2 - x \Rightarrow x^2 + x - 2 = 0 \Rightarrow x_1 = -2,\ x_2 = 1\). Точки: \((-2;\,4)\) и \((1;\,1)\).

При \(x\in[-2;1]\), например \(x = 0\): \(2 - 0 = 2 > 0 = 0^2\), значит прямая \(y = 2-x\) лежит выше параболы.

2. Расстановка пределов

\[D = \{-2 \le x \le 1,\ \ x^2 \le y \le 2 - x\},\qquad I = \int_{-2}^{1} dx \int_{x^2}^{2-x} (x+1)\,dy.\]

3. Внутренний интеграл

\[\int_{x^2}^{2-x}(x+1)\,dy = (x+1)\,y\Big|_{x^2}^{2-x} = (x+1)(2 - x - x^2) = 2 + x - 2x^2 - x^3.\]

4. Внешний интеграл

\[I = \int_{-2}^{1}(2 + x - 2x^2 - x^3)\,dx = \left(2x + \frac{x^2}{2} - \frac{2x^3}{3} - \frac{x^4}{4}\right)\Bigg|_{-2}^{1}.\] \[\text{при } x=1:\ \ 2 + \frac12 - \frac23 - \frac14 = \frac{24 + 6 - 8 - 3}{12} = \frac{19}{12};\] \[\text{при } x=-2:\ \ -4 + 2 + \frac{16}{3} - 4 = -\frac23 = -\frac{8}{12}.\] \[I = \frac{19}{12} - \left(-\frac{8}{12}\right) = \frac{27}{12} = \frac94.\]
Ответ: \(I = \dfrac94 = 2{,}25\).

Задача 6.2

Перейдя к полярным координатам, вычислить \(\displaystyle\iint_G \frac{y}{\sqrt{x^2+y^2}}\,dx\,dy\), где \(G = \{x^2+y^2 \le 1,\ x^2+y^2 \le 2y\}\).

1. Область G (чертёж обязателен)

\(x^2 + y^2 \le 1\) — круг радиуса 1 с центром \((0;0)\).

\(x^2 + y^2 \le 2y \iff x^2 + (y-1)^2 \le 1\) — круг радиуса 1 с центром \((0;1)\).

\(G\) — общая часть двух кругов («линза»). Пересечение окружностей: вычитаем уравнения, \(2y = 1 \Rightarrow y = \frac12,\ x = \pm\frac{\sqrt3}{2}\).

2. Переход к полярным координатам

\(x = r\cos\varphi,\ y = r\sin\varphi,\ dx\,dy = r\,dr\,d\varphi\) (якобиан \(J = r\)).

Границы: \(x^2+y^2 = 1 \Rightarrow r = 1\); \(\ x^2+y^2 = 2y \Rightarrow r^2 = 2r\sin\varphi \Rightarrow r = 2\sin\varphi\).

Подынтегральная функция: \(\dfrac{y}{\sqrt{x^2+y^2}} = \dfrac{r\sin\varphi}{r} = \sin\varphi\).

Лучи через точки пересечения: \(2\sin\varphi = 1 \Rightarrow \varphi = \frac{\pi}{6},\ \varphi = \frac{5\pi}{6}\). Значит, \(r\) идёт от \(0\) до

  • \(2\sin\varphi\) при \(\varphi \in [0;\,\frac{\pi}{6}]\) и \(\varphi\in[\frac{5\pi}{6};\,\pi]\) (там ближе окружность \(r = 2\sin\varphi\));
  • \(1\) при \(\varphi \in [\frac{\pi}{6};\,\frac{5\pi}{6}]\).

Область и функция \(\sin\varphi\) симметричны относительно оси \(Oy\), поэтому считаем правую половину \(\varphi\in[0;\frac{\pi}{2}]\) и удваиваем:

\[I = 2\left(\int_{0}^{\pi/6} d\varphi\int_0^{2\sin\varphi}\sin\varphi\cdot r\,dr \;+\; \int_{\pi/6}^{\pi/2} d\varphi\int_0^{1}\sin\varphi\cdot r\,dr\right) = 2(I_1 + I_2).\]

3. Вычисление \(I_1\)

\[\int_0^{2\sin\varphi} r\,dr = \frac{r^2}{2}\Big|_0^{2\sin\varphi} = 2\sin^2\varphi,\qquad I_1 = \int_0^{\pi/6} 2\sin^3\varphi\,d\varphi.\]

\(\sin^3\varphi\,d\varphi = (1-\cos^2\varphi)\sin\varphi\,d\varphi = -(1-\cos^2\varphi)\,d(\cos\varphi)\), откуда \(\int\sin^3\varphi\,d\varphi = -\cos\varphi + \dfrac{\cos^3\varphi}{3}\).

\[I_1 = 2\left(-\cos\varphi + \frac{\cos^3\varphi}{3}\right)\Bigg|_0^{\pi/6} = 2\left[\left(-\frac{\sqrt3}{2} + \frac{\sqrt3}{8}\right) - \left(-1 + \frac13\right)\right] = 2\left(\frac23 - \frac{3\sqrt3}{8}\right) = \frac43 - \frac{3\sqrt3}{4}.\]

(Здесь \(\cos^3\frac{\pi}{6} = \left(\frac{\sqrt3}{2}\right)^3 = \frac{3\sqrt3}{8}\), делённое на 3 даёт \(\frac{\sqrt3}{8}\).)

4. Вычисление \(I_2\)

\[\int_0^1 r\,dr = \frac12,\qquad I_2 = \frac12\int_{\pi/6}^{\pi/2}\sin\varphi\,d\varphi = \frac12\left(-\cos\varphi\right)\Big|_{\pi/6}^{\pi/2} = \frac12\left(0 + \frac{\sqrt3}{2}\right) = \frac{\sqrt3}{4}.\]

5. Итог

\[I = 2\left(\frac43 - \frac{3\sqrt3}{4} + \frac{\sqrt3}{4}\right) = 2\left(\frac43 - \frac{\sqrt3}{2}\right) = \frac83 - \sqrt3.\]
Ответ: \(I = \dfrac83 - \sqrt3 \approx 0{,}935\).

Задача 7.4

Разложить по формуле Маклорена до \(o(\rho^2)\), где \(\rho = \sqrt{x^2+y^2+z^2}\), функцию \(f = \cos x\cos y\cos z - \cos(x+y+z)\).

Способ 1 — через известные разложения

Используем \(\cos t = 1 - \dfrac{t^2}{2} + o(t^2)\).

\[\cos x\cos y\cos z = \left(1 - \frac{x^2}{2}\right)\left(1 - \frac{y^2}{2}\right)\left(1 - \frac{z^2}{2}\right) + o(\rho^2) = 1 - \frac{x^2+y^2+z^2}{2} + o(\rho^2)\]

(произведения вида \(\frac{x^2y^2}{4}\) имеют 4-й порядок малости и уходят в \(o(\rho^2)\)).

\[\cos(x+y+z) = 1 - \frac{(x+y+z)^2}{2} + o(\rho^2) = 1 - \frac{x^2+y^2+z^2 + 2xy + 2xz + 2yz}{2} + o(\rho^2).\]

Вычитаем:

\[f = -\frac{x^2+y^2+z^2}{2} + \frac{x^2+y^2+z^2 + 2xy+2xz+2yz}{2} + o(\rho^2) = xy + xz + yz + o(\rho^2).\]

Способ 2 — проверка через производные (формула Тейлора)

\(f(0,0,0) = 1 - 1 = 0\).

\(f'_x = -\sin x\cos y\cos z + \sin(x+y+z)\), в нуле \(=0\); аналогично \(f'_y(0) = f'_z(0) = 0\).

\(f''_{xx} = -\cos x\cos y\cos z + \cos(x+y+z)\), в нуле \(= -1 + 1 = 0\); аналогично \(f''_{yy}(0) = f''_{zz}(0) = 0\).

\(f''_{xy} = \sin x\sin y\cos z + \cos(x+y+z)\), в нуле \(= 0 + 1 = 1\); аналогично \(f''_{xz}(0) = f''_{yz}(0) = 1\).

\[f = f(0) + df(0) + \frac{1}{2!}d^2f(0) + o(\rho^2) = 0 + 0 + \frac12\left(2xy + 2xz + 2yz\right) + o(\rho^2).\]
Ответ: \(f = xy + xz + yz + o(\rho^2)\), \(\ \rho\to 0\).
